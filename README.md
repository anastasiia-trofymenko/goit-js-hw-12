# 🔍 Image Search WEB Application — Portfolio Project

## 📌 Overview

This project is an interactive frontend application developed as part of a **JavaScript course assignment**.
It allows users to search for images using an external API and displays results in a responsive, user‑friendly gallery.

The application focuses on asynchronous JavaScript, API integration, dynamic DOM updates, and polished user interaction.

🔗 **Live Demo:** https://anastasiia-trofymenko.github.io/goit-js-hw-12/

---

## ✨ Highlights

- Image search powered by an external API
- Responsive gallery layout
- Dynamic rendering based on user input
- Pagination with “Load more” functionality
- Smooth UI feedback and notifications
- Clean and minimal interface

---

## 🛠 Tech Stack

- **HTML5** — semantic markup
- **CSS3** — responsive layout and styling
- **JavaScript (ES6+)** — application logic
- **Axios / Fetch API** — asynchronous data fetching
- **SimpleLightbox** — image preview functionality
- **Git / GitHub** — version control
- **GitHub Pages** — deployment

---

## 👩‍💻 My Role

This project was completed individually as part of a JavaScript frontend course.

My responsibilities included:

- Implementing image search functionality
- Integrating and handling responses from a REST API
- Managing asynchronous logic and pagination
- Updating the DOM dynamically based on search results

## 🚀 Run Locally

1. Clone the repository:

```bash

```

2. Navigate to the project directory:

```bash
cd goit-js-hw-12
```

3. Open `index.html` in your browser.
